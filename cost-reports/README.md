# cost-reports

Saved AWS cost estimates from the **[AWS Cost Calculator](../cost-dashboard/)** dashboard.

Each estimate is saved here as a **`.html`** (self-contained, styled, openable in a browser) and/or
**`.md`** (Markdown) file, named by whatever you type in the dashboard's *report name* box. The
dashboard's **Download / Save → HTML → GitHub** (or **Markdown → GitHub**) option opens GitHub's
prefilled new-file editor pointed at this directory — review and commit (it can open a PR).

Prices in these reports are AWS **On-Demand list rates, approximate** — they exclude Free Tier,
Savings Plans / Reserved Instances, volume & EDP discounts, and taxes. See `docs/AWS_PRICING.md`.
